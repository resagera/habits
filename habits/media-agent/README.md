# habits-media-agent

Домашний медиасервер для ТВ-плеера: отдаёт файлы из разрешённых папок по
локальной сети и страницу плеера, которую открывают на приставке.

Этап 1 из четырёх: агент самодостаточен и проверяется на приставке **без**
серверной обвязки. Пульт в мини-аппе, связывание по коду и QR — следующие этапы.

## Почему так

- **Слушает только `127.0.0.1`.** На роутере нестандартные порты закрыты,
  наружу агента выставляет nginx на 80-м. Отсюда `MEDIA_BASE` — префикс, под
  которым агент виден снаружи: без него ссылки внутри страницы уедут в корень.
- **Играет только MP4.** Проверено на приставке: MKV и AVI она не открывает,
  хотя кодеки внутри обычно годные — HEVC и 10 бит берёт спокойно. Поэтому
  MKV нужно перепаковать, а не пережать.
- **Живого перекодирования нет.** Приставка (Xiaomi Mi TV, Chrome 150 в WebView)
  берёт как есть почти всё, что уже в MP4. Остальное
  дешевле один раз перекодировать в фоне, чем городить поток, который надо
  перезапускать при каждой перемотке.
- **Разбор по требованию.** ffprobe запускается, когда открыли папку, а не
  сплошным обходом при старте: файлов тут восемь тысяч, а за вечер открывают
  две-три папки. Результат кэшируется на диск.
- **Наружу уходят идентификаторы, а не пути.** Клиент не знает раскладку дисков
  и не может задать путь, поэтому выйти за пределы библиотеки ему нечем.
  Ссылки на файлы подписаны: в локальной сети живёт не только приставка.

## Запуск

```bash
GOTOOLCHAIN=auto /usr/local/go/bin/go build -o ~/bin/habits-media-agent .
~/bin/habits-media-agent
```

Настройки читаются из `~/.config/habits-media-agent.conf` (или из файла,
указанного в `MEDIA_CONFIG`). Список папок — длинная строка с разделителями, и
держать её в переменной окружения неудобно; в файле пишется по папке на строку:

```ini
# путь | Название | вид (video, clips, music, photo)
roots = /mnt/serials | Сериалы      | video
roots = /mnt/video   | Видеоролики  | clips
roots = /mnt/foto    | Фото         | photo
roots = /mnt/music   | Музыка       | music

addr = 127.0.0.1:8410
base = /tv
```

Порядок: умолчания → файл → переменные окружения. Окружение главнее файла,
чтобы разовый запуск с другой папкой не требовал его правки:

```bash
MEDIA_ROOTS='/tmp/test|Проба|video' ~/bin/habits-media-agent
```

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MEDIA_ROOTS` / `roots` | — | папки через `;`, каждая `путь\|Название\|вид`; вид: `video`, `clips`, `music`, `photo` |
| `MEDIA_ADDR` / `addr` | `127.0.0.1:8410` | что слушать |
| `MEDIA_BASE` / `base` | `/tv` | внешний префикс за проксей |
| `MEDIA_CACHE` / `cache` | `~/.cache/habits-media` | разбор, ключ подписи, перекодированные файлы |
| `MEDIA_ADMIN_PIN` / `admin_pin` | — | PIN админки на странице; не задан — админка выключена |
| `MEDIA_TRASH_DAYS` / `trash_days` | `3` | сколько дней удалённое лежит в корзине до стирания |

Нужен `ffmpeg` с `ffprobe` в `PATH`.

## nginx

```nginx
location /tv/ {
    proxy_pass http://127.0.0.1:8410;   # без слэша на конце: префикс /tv нужен агенту
    proxy_http_version 1.1;
    proxy_set_header Host $host;

    # видео через буфер во временный файл гонять нельзя: перемотка встанет,
    # а диск забьётся копиями серий
    proxy_buffering off;
    proxy_max_temp_file_size 0;
    proxy_read_timeout 1h;
}
```

Открывать на приставке: `http://<адрес-компьютера>/tv/`

На экране приставки показан **код для пульта** — наберите его на странице
«Пульт ТВ» в приложении. Адрес компьютера при этом знать не нужно.

Имя комнаты постоянное (`имя-машины-хвост`, лежит в `MEDIA_CACHE/room`) и НЕ
зависит от адреса в сети: иначе смена адреса роутером убивала бы сохранённую
на телефоне приставку. Переопределяется через `MEDIA_ROOM`.

## Как добавить сериал или фильм

Кодировать на слабой машине с агентом долго, поэтому MP4 собираются на
дев-машине и уезжают по сети. Доступ — `~/.config/habits-recode.conf`
(host/user/password, 0600) или `RECODE_HOST/USER/PASS`.

**Одна команда на всё** — `send-series.py`. Принимает папку сериала (с папками
сезонов внутри) или файл фильма и сам решает по каждому файлу:

| Что в файле | Что делается |
|---|---|
| видео h264 / hevc / av1 / vp9 | копируется как есть — быстро, без потерь |
| видео mpeg4 (старые AVI), прочее | перекодируется в h264 (~20× реального времени) |
| звук AAC / MP3 в стерео | копируется |
| звук AC3, DTS, 5.1 | в AAC стерео |
| субтитры, обложки | отбрасываются |

```bash
S=habits/media-agent/send-series.py
python3 $S "/путь/Сериал" --audio 0 --dry-run      # 1. план: что копируется, что перекодируется, сколько ехать
python3 $S "/путь/Сериал" --audio 0                # 2. поехали (прерывать можно: повтор пропустит готовое)
python3 $S "/путь/Film.2020.1080p.mkv" --audio 0 --name "Фильм (2020)"   # фильм
```

- `--audio 0` — только первая дорожка (обычно русская); без ключа уедут все,
  но приставка играет только первую (см. ниже).
- Для долгих прогонов — `nohup … > лог 2>&1 &`; для временных файлов нужно
  место примерно на два собранных файла (`--workdir`).
- Сериал ложится в `/mnt/media/rudb/media/serials/<имя папки>`, фильм — в
  `/home/res/rudb/media/films`. Постер найдётся сам при первом показе.
- Имя папки сериала становится названием и запросом для постера: лучше
  «Legion (2017)», чем «Legion.S01-03.1080p.LostFilm».

## Как добавить фотографии

`send-photos.py` отдаёт ZIP-архив на мини-сервер одним файлом и распаковывает
его там в `/home/res/rudb/media/foto`:

```bash
P=habits/media-agent/send-photos.py
python3 $P "/путь/Свадьба.zip" --dry-run               # план: альбом, число снимков, место
python3 $P "/путь/Свадьба.zip"                         # поехали
python3 $P "/путь/снимки.zip" --name "Отпуск 2026"     # своё имя альбома
python3 $P "/путь/Свадьба-ещё.zip" --merge             # дописать в существующий альбом
```

- Папка внутри архива становится альбомом; снимки прямо в корне архива —
  альбом по имени архива (или `--name`). Вложенные папки сохраняются.
- Распаковка идёт в скрытую папку и переезжает на место одним `mv`: медиатека
  не увидит полупустой альбом. `__MACOSX`, `.DS_Store`, `Thumbs.db` не
  распаковываются. Альбом с таким именем уже есть — без `--merge` скрипт
  остановится.
- В конце скрипт открывает альбом у агента, и тот в фоне собирает превью и
  копии под экран (~1 с на снимок 24 Мп на i3): к просмотру всё готово.

Видеоролики кладутся в `/home/res/rudb/media/video` как есть (MP4) — вручную
или тем же `send-series.py` с `--dest-root /home/res/rudb/media/video`.

`recode-remote.py` — другое: перекодирует то, что **уже лежит** в библиотеке
мини-сервера (забрать → собрать здесь → вернуть), удаляя исходники; ночью
пережидает пропажу сети. `send-film.py` — старый вариант для одного фильма.

### Звуковые дорожки на приставке

Приставка играет **только первую** дорожку MP4: `<video>` в Chrome и WebView не
умеет переключать встроенные дорожки (API `audioTracks` выключен в Chromium, проверено
на Chrome 136). Поэтому по умолчанию берём одну нужную. Как получить выбор
перевода — см. BACKLOG («несколько звуковых дорожек»).

## Подготовка библиотеки

Приставка играет только MP4: MKV и AVI она не открывает, хотя кодеки внутри
чаще всего подходящие. `tvconvert.py` готовит библиотеку заранее — и заодно
раскладывает её под Plex. Ничего не делает без `--apply`.

```bash
python3 tvconvert.py plan    /путь/к/сериалу              # что нашлось
python3 tvconvert.py convert /путь/к/сериалу --apply      # в MP4
python3 tvconvert.py rename  /путь/к/сериалу --apply      # имена под Plex
```

MKV с годными кодеками только **перепаковывается** (`-c copy`) — это идёт со
скоростью диска и не трогает качество. Настоящее перекодирование нужно лишь
там, где не годится сам кодек: звук AC3/DTS или видео MPEG-4 из AVI.

```ini
After=network.target

[Service]

```

```bash

```

## Два режима плеера

После «Начать» в шапке переключатель: **🎬 Визуальный** (по умолчанию) и
**📁 Файлы** (дерево папок, как раньше). Выбор запоминается на приставке.

Визуальный режим объединяет все библиотеки и раскладывает их **по структуре
папок**, а не по названиям:

- **сериал** — папка, внутри которой папки с видео (сезоны);
- **фильм** — видеофайл или папка ровно с одним видеофайлом;
- папка с несколькими видео без сезонов — сериал из одного сезона;
- **музыка** — каждая папка, где прямо лежат треки (пустые не показываются);
- **видеоролики** (библиотека вида `clips`) — ролик прямо в корне своей
  плиткой, папка с роликами — плиткой на папку; ролики папки идут подряд;
- **фото** (вид `photo`) — папки первого уровня, где есть снимки (хоть во
  вложенных папках); снимки прямо в корне — одной плиткой.

Разделы «Видеоролики» и «Фото» пустыми не показываются.

**Фото.** В папке сверху снимок на большую часть экрана, снизу полоса: снимки,
за ними вложенные папки. Стрелки ходят по полосе, снимок сверху меняется вслед
за фокусом; OK — во весь экран, там стрелки листают по кругу, «Назад»
возвращает к полосе на том же снимке. Приставке уходят не оригиналы (6–8 МБ),
а копии: превью до 480 px и экранная до 1920×1080, с поворотом по EXIF. Копии
собираются по требованию стандартной библиотекой Go (без внешних программ) и
лежат в `MEDIA_CACHE/photos` с ключом «путь + размер + время правки»; открыли
папку — агент в фоне готовит копии всех её снимков, по одному. WebP и GIF
отдаются как есть.

**Постеры** агент ищет сам при первом показе плитки — IMDb для латинских
названий (с разбором «фильм или сериал» и года), Википедия для кириллических —
и кладёт **рядом** с фильмом или папкой сериала под тем же именем
(`Fauda/` → `Fauda.jpg`, `Фильм.mp4` → `Фильм.jpg`). Неудачный поиск
запоминается на сутки. Свой постер можно подложить руками тем же именем — он
главнее найденного. Нет прав писать в папку — картинка ляжет в кэш агента.
Для видеороликов и фото постеры **не ищутся**: по имени домашнего файла нашлась
бы чужая картинка. Положенная рядом руками (`Ролик.mp4` → `Ролик.jpg`, папка →
`Папка.jpg` или `poster.jpg` внутри) показывается.

Сериал играет **сезон за сезоном**: после последней серии сезона плеер сам
берёт первую серию следующего (и в визуальном режиме, и в «Файлах»). На
главной есть **очередь** — фильмы и сериалы по порядку.

**Продолжить просмотр** — первый раздел главной: по записи на сериал или фильм,
свежие первыми (до 20, старше полугода забываются). Хранится на агенте в
`progress.json` кэша, а не в браузере приставки. Плеер шлёт id файла и секунду
раз в 15 с, на паузе, при выходе из плеера и в конце серии; к какому сериалу
относится серия, агент выясняет по папкам сам. Правила:

- первая минута чужой серии место не затирает (случайное включение);
- осталось меньше 2 минут или 3% — серия досмотрена, запись переходит на
  следующую серию с нуля, в том числе через сезон; досмотрен сериал или фильм —
  запись удаляется;
- возобновление ставит на 5 секунд раньше места остановки;
- после перекодирования (`S01E05.avi` → `S01E05.mp4` меняет id) запись находит
  серию по пути без расширения.

## Приложение для Android TV

Браузер приставки работает курсором; приложение `habits/tv-app` открывает эту же
страницу и передаёт ей настоящие стрелки пульта. Страница узнаёт его по
`HabitsTV/` в User-Agent: сама нажимает «Начать», показывает «⚙ Адрес», а кнопку
«Назад» пульта обрабатывает `window.habitsBack()`. Во весь экран OK пульта
(Enter) и Play/Pause ставят видео на паузу и запускают снова, стрелки влево и
вправо мотают на 30 с (поверх видео на секунду видно позицию).

## Музыка

- **«Музыка на паузе»** — галочка на панели плеера. Видео на паузу — играет
  музыка (очередь пуста — первая музыкальная папка), видео пошло — музыка на
  паузу и в следующий раз продолжит с того же места. Паузы, которые ставит сама
  страница (выход в каталог, «⏹», конец серии), не в счёт. Помнится на сессию
  страницы (`sessionStorage`).
- **Как играть** — «➡ Один раз» (очередь до конца и стоп), «🔁 Весь плейлист»
  (по кругу), «🔂 Один трек» (текущий по кругу); **порядок** — 🔢 прямой или
  🔀 случайный: текущий трек остаётся на месте, остальные звучат по разу,
  «Играть всё» начинает со случайного. Оба выбора — в `localStorage` приставки. В обычном браузере в шапке
справа значок Android — ссылка на APK, если он выложен (`tv-app/build.sh
--deploy` кладёт его в `MEDIA_CACHE/app/habits-tv.apk`).

## Оформление, заставки, сон, слайд-шоу

- **Фон страницы** — админка, «Оформление»: снимок из «Фото» (стрелками) или
  файл с компьютера; размытие и затемнение — стилями страницы, на ходу. Лежит
  в `MEDIA_CACHE/app/background.jpg`, настройки — `looks.json`. На экране
  сериала и папки роликов вместо общего фона — их постер, сильно размытый. В
  плеере и «Файлах» фона нет.
- **Обложки** — «🎨» у строки админки: папке — скрытый `.cover.jpg` внутрь
  (главнее всего, переезжает и удаляется вместе с папкой), файлу — `Имя.jpg`
  рядом. Музыка и альбомы фото показывают только свои обложки (альбом без неё
  — первый снимок).
- **Заставка и титры** — «✂ Заставка и титры» под видео: начало и конец
  заставки, начало титров, «пропускать сам». Отметки на весь сериал
  (`marks.json`, ключ как у «Продолжить просмотр»); титры считаются от конца
  серии. Во время заставки — «⏭ Пропустить заставку», на титрах — «Следующая
  серия через 10 с»; во весь экран OK жмёт кнопку, «Назад» отказывается.
- **🌙 Сон** — через 15/30/60/90 минут или после этой серии: звук за 15 с
  уходит, видео и музыка встают на паузу.
- **Во весь экран** стрелки ↑↓ — ±5 минут или громкость (выбор в «Оформлении»).
- **Ролики в альбомах фото** — видео рядом со снимками: в полосе со значком
  ▶ (кадр вынимает ffmpeg), смотрятся в просмотрщике во весь экран.
- **▶ Слайд-шоу** — первая кнопка полосы альбома: каждые 3–12 с, по порядку или
  вперемешку, с плавной сменой, под музыку из библиотеки — папкой по кругу или
  одной песней по кругу. OK — пауза, «Назад» — выход (музыка встаёт, прежний
  режим повтора возвращается). Настройки запоминаются на приставке.

## «Инфо», плейлисты, загрузка музыки, статистика

- **ℹ Инфо** у фильмов и сериалов на главной: описание, год, жанры, оценки,
  актёры. Агент ищет при первом открытии (`GET /api/info`): подсказки IMDb →
  Wikidata по id IMDb (жанры, актёры, дата, оценки критиков) → Википедия
  (описание, ru или en) → TVmaze для сериалов (рейтинг зрителей). Кириллическое
  название — через поиск Википедии. Хранится рядом с постером: `Имя.info.json`
  (едет при переименовании и в корзину). В админке «ℹ» у строки: найти заново,
  «искать как…», поправить поля руками, очистить. В User-Agent — ссылка на
  репозиторий и не чаще запроса в 300 мс: иначе Wikimedia отвечает «too many requests».
- **Плейлисты** — `playlists.json` в кэше: «＋» у трека, «＋ Всю папку в
  плейлист»; плейлисты первыми в «Музыке», доступны в выборе музыки под фильм,
  в слайд-шоу и «Музыке на паузе».
- **〰 Плавно** — переход между треками за 4 с (второй `<audio>`).
- **Альбом ZIP** — админка, «Медиатека» → «📦 Выбрать ZIP» (браузер на
  компьютере). Загрузка частями по 768 КБ (`/api/admin/upload`): у nginx на
  res-i3 предел тела 1 МБ. Папка внутри архива — альбом; только треки,
  картинки, `.lrc`/`.cue`; имена CP866 из Windows-архиваторов декодируются.
- **Статистика** — админка, «Статистика»: часы по дням за 7 или 30 дней и
  самое смотримое (`stats.json`; в зачёт только воспроизведение).
- **Отправить на ТВ** — «Пульт ТВ» в Telegram → «🖼 Фото или видео»: файл через
  прод (`/api/v1/tv/cast`), на приставке слой поверх всего, «Назад» — закрыть.

## Админка

Значок ⚙ в шапке страницы (рядом с 🔄 «обновить» и значком приложения).
Закрыта PIN-кодом `admin_pin`: в домашнем вайфае живёт не только приставка, а
здесь удаляют сериалы. PIN спрашивается один раз на устройстве и хранится в его
браузере; пять неверных подряд — пауза 5 минут. Без `admin_pin` админка выключена.

- **Медиатека** — все разделы с настоящими путями и размерами. «✏ Имя»
  переименовывает на диске: у файла расширение сохраняется само, постер-сосед
  (`Имя.jpg`) и записи «Продолжить просмотр» переезжают следом. «📂 Файлы» —
  внутрь: сезоны, серии, посторонние файлы. «🖼 Постер» — найти заново.
- **Удаление** — в корзину `<корень библиотеки>/.habits-trash/<id>/` (тот же
  диск, переезд мгновенный) вместе с постером-соседом. Через `trash_days` дней
  стирается само (проверка раз в 30 минут), до этого — «↩ Вернуть» (не
  затирает то, что появилось на старом месте) или «✖ Стереть» сразу. Список —
  `MEDIA_CACHE/trash.json`. Корень библиотеки не удаляется и не переименовывается.
- **Уведомления** — о переносе в корзину, возврате и стирании агент пишет
  владельцу приставки в Telegram через прод: `POST /api/v1/tv/notify`
  (адрес — из `hub`, `wss://…/socket` → `https://…/notify`), пропуск — ключ
  комнаты. Пока к приставке не подключали пульт, писать некому.
- **Обслуживание** — место на дисках библиотек, копии фото (очистить), ненайденные
  постеры (искать сейчас), «Продолжить просмотр» (очистить), проверочное
  уведомление, «забыть PIN» на этом устройстве.

## API (локальный)

| Запрос | Ответ |
|---|---|
| `GET /api/libraries` | список библиотек |
| `GET /api/browse?id=` | содержимое библиотеки или папки |
| `GET /api/catalog` | фильмы, сериалы с сезонами, видеоролики, фото и музыка для визуального режима |
| `GET /api/photos?id=` | снимки папки (ссылки на превью и экранную копию) и вложенные папки со снимками |
| `GET /photo/{id}?k=&s=thumb\|view` | копия снимка: превью или под экран (соберёт, если нет) |
| `GET /api/item?id=` | один файл с разбором и ссылкой |
| `GET /api/next-season?id=<файл>` | серии следующего сезона того же сериала |
| `GET /poster/{id}?k=&kind=` | постер плитки (для фильмов и сериалов найдёт и сохранит рядом, если нет) |
| `GET /api/progress` | «Продолжить просмотр», свежие сверху |
| `PUT` или `POST /api/progress` `{file, position, duration}` | запомнить место; POST — для `sendBeacon` при закрытии страницы |
| `DELETE /api/progress/{key}` | убрать запись |
| `GET /app/habits-tv.apk` | приложение для Android TV (404, пока не выложено) |
| `GET /api/info?id=` · `POST /api/admin/info` | «Инфо» о фильме или сериале; найти заново, поправить, очистить |
| `GET`/`POST /api/playlists` · `GET /api/playlists/{id}` · `POST …/add` · `…/remove` · `…/rename` · `DELETE …/{id}` | свои плейлисты |
| `POST /api/admin/upload` · `PUT …/{id}?offset=` · `POST …/{id}/finish?target=music-zip\|background\|cover` | загрузка частями |
| `GET /api/stats?days=` | статистика просмотра |
| `GET /api/settings` · `GET /background` | оформление для страницы и картинка фона |
| `GET` / `PUT /api/marks?file=` `{file, intro_start, intro_end, credits_from_end, auto_skip, reset}` | заставка и титры сериала |
| `POST /api/admin/settings` · `POST`/`DELETE /api/admin/image?target=background\|cover&id=` | оформление, фон и обложки (тело — картинка или `{photo_id}`) |
| `GET /api/admin/check` · `overview` · `children?id=` · `trash` · `service` | админка (заголовок `X-Admin-Pin`) |
| `POST /api/admin/rename {id,name}` · `delete {id}` · `poster/reset {id}` | переименовать, в корзину, постер заново |
| `POST /api/admin/trash/{id}/restore` · `…/purge` · `service/{action}` | вернуть, стереть, обслуживание |
| `GET /api/jobs` | очередь перекодирования |
| `POST /api/jobs` `{"id","profile"}` | поставить задачу (профиль по умолчанию — из вердикта разбора) |
| `POST /api/jobs/{id}/stop` | снять задачу |
| `GET /media/{id}?k=` | файл, с поддержкой Range |

Профили: `remux` (только контейнер), `audio` (видео копируется, звук в AAC),
`video` (всё заново). Результат ложится в кэш, и по той же ссылке начинает
отдаваться он вместо оригинала.
