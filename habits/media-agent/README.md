# habits-media-agent

Домашний медиасервер для ТВ-плеера: отдаёт файлы из разрешённых папок по
локальной сети и страницу плеера, которую открывают на приставке.

Этап 1 из четырёх: агент самодостаточен и проверяется на приставке **без**
серверной обвязки. Пульт в мини-аппе, связывание по коду и QR — следующие этапы.

## Почему так

- **Слушает только `127.0.0.1`.** На роутере нестандартные порты закрыты,
  наружу агента выставляет nginx на 80-м. Отсюда `MEDIA_BASE` — префикс, под
  которым агент виден снаружи: без него ссылки внутри страницы уедут в корень.
- **Играет только MP4.** Проверено на приставке: MKV и AVI она не открывает,
  хотя кодеки внутри обычно годные — HEVC и 10 бит берёт спокойно. Поэтому
  MKV нужно перепаковать, а не пережать.
- **Живого перекодирования нет.** Приставка (Xiaomi Mi TV, Chrome 150 в WebView)
  берёт как есть почти всё, что уже в MP4. Остальное
  дешевле один раз перекодировать в фоне, чем городить поток, который надо
  перезапускать при каждой перемотке.
- **Разбор по требованию.** ffprobe запускается, когда открыли папку, а не
  сплошным обходом при старте: файлов тут восемь тысяч, а за вечер открывают
  две-три папки. Результат кэшируется на диск.
- **Наружу уходят идентификаторы, а не пути.** Клиент не знает раскладку дисков
  и не может задать путь, поэтому выйти за пределы библиотеки ему нечем.
  Ссылки на файлы подписаны: в локальной сети живёт не только приставка.

## Запуск

```bash
GOTOOLCHAIN=auto /usr/local/go/bin/go build -o ~/bin/habits-media-agent .
~/bin/habits-media-agent
```

Настройки читаются из `~/.config/habits-media-agent.conf` (или из файла,
указанного в `MEDIA_CONFIG`). Список папок — длинная строка с разделителями, и
держать её в переменной окружения неудобно; в файле пишется по папке на строку:

```ini
# путь | Название | вид (video, clips, music, photo)
roots = /mnt/serials | Сериалы      | video
roots = /mnt/video   | Видеоролики  | clips
roots = /mnt/foto    | Фото         | photo
roots = /mnt/music   | Музыка       | music

addr = 127.0.0.1:8410
base = /tv
```

Порядок: умолчания → файл → переменные окружения. Окружение главнее файла,
чтобы разовый запуск с другой папкой не требовал его правки:

```bash
MEDIA_ROOTS='/tmp/test|Проба|video' ~/bin/habits-media-agent
```

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MEDIA_ROOTS` / `roots` | — | папки через `;`, каждая `путь\|Название\|вид`; вид: `video`, `clips`, `music`, `photo` |
| `MEDIA_ADDR` / `addr` | `127.0.0.1:8410` | что слушать |
| `MEDIA_BASE` / `base` | `/tv` | внешний префикс за проксей |
| `MEDIA_CACHE` / `cache` | `~/.cache/habits-media` | разбор, ключ подписи, перекодированные файлы |
| `MEDIA_ADMIN_PIN` / `admin_pin` | — | PIN админки на странице; не задан — админка выключена |
| `MEDIA_TRASH_DAYS` / `trash_days` | `3` | сколько дней удалённое лежит в корзине до стирания |

Нужен `ffmpeg` с `ffprobe` в `PATH`.

## nginx

```nginx
location /tv/ {
    proxy_pass http://127.0.0.1:8410;   # без слэша на конце: префикс /tv нужен агенту
    proxy_http_version 1.1;
    proxy_set_header Host $host;

    # видео через буфер во временный файл гонять нельзя: перемотка встанет,
    # а диск забьётся копиями серий
    proxy_buffering off;
    proxy_max_temp_file_size 0;
    proxy_read_timeout 1h;
}
```

Открывать на приставке: `http://<адрес-компьютера>/tv/`

На экране приставки показан **код для пульта** — наберите его на странице
«Пульт ТВ» в приложении. Адрес компьютера при этом знать не нужно.

Имя комнаты постоянное (`имя-машины-хвост`, лежит в `MEDIA_CACHE/room`) и НЕ
зависит от адреса в сети: иначе смена адреса роутером убивала бы сохранённую
на телефоне приставку. Переопределяется через `MEDIA_ROOM`.

## Как добавить сериал или фильм

Кодировать на слабой машине с агентом долго, поэтому MP4 собираются на
дев-машине и уезжают по сети. Доступ — `~/.config/habits-recode.conf`
(host/user/password, 0600) или `RECODE_HOST/USER/PASS`.

**Одна команда на всё** — `send-series.py`. Принимает папку сериала (с папками
сезонов внутри) или файл фильма и сам решает по каждому файлу:

| Что в файле | Что делается |
|---|---|
| видео h264 / hevc / av1 / vp9 | копируется как есть — быстро, без потерь |
| видео mpeg4 (старые AVI), прочее | перекодируется в h264 (~20× реального времени) |
| звук AAC / MP3 в стерео | копируется |
| звук AC3, DTS, 5.1 | в AAC стерео |
| субтитры, обложки | отбрасываются |

```bash
S=habits/media-agent/send-series.py
python3 $S "/путь/Сериал" --audio 0 --dry-run      # 1. план: что копируется, что перекодируется, сколько ехать
python3 $S "/путь/Сериал" --audio 0                # 2. поехали (прерывать можно: повтор пропустит готовое)
python3 $S "/путь/Film.2020.1080p.mkv" --audio 0 --name "Фильм (2020)"   # фильм
python3 $S "/путь/Гарри Поттер Коллекция" --films --audio 0             # папка ФИЛЬМОВ
python3 $S "/путь/Film.mkv" --audio 0,11                                # две дорожки
python3 $S "/путь/Film.mkv" --audio 0 --scale 720p --crf 22             # мельче картинка
python3 $S "/путь/Film.mkv" --audio 0 --bitrate 6M                      # задать битрейт
```

- `--audio 0` — только первая дорожка (обычно русская); без ключа уедут все,
  но приставка играет только первую (см. ниже). Можно перечислить нужные:
  `--audio 0,11` возьмёт дубляж и оригинал — пригодится на будущее, играть
  приставка всё равно будет первую из них.
- `--scale`, `--crf`, `--bitrate`, `--preset` — уменьшить картинку («720p»,
  «1280x720», «70%»), качество (18 лучше … 28 мельче, по умолчанию 21) или
  прямо битрейт («6M», «2500k»; один проход с потолком 1,5× и буфером на две
  секунды). `--crf` держит качество и отпускает размер, `--bitrate` — наоборот.
  `--preset slow` плотнее сжимает, но идёт впятеро дольше `veryfast`. Любой из них означает, что
  видео пойдёт **заново**, даже если его можно было скопировать: на этой машине
  1080p идёт вчетверо быстрее реального времени, а 720p — ненамного быстрее,
  потому что раскодировать исходник всё равно надо целиком. Уменьшать
  разрешение ради места обычно не стоит: у приставки экран 1080p, и выгоднее
  оставить размер, но сбросить битрейт (`--crf 21` превращает 13–17 Мбит/с
  ремукса в ~3,5 Мбит/с).
- Для долгих прогонов — `nohup … > лог 2>&1 &`; для временных файлов нужно
  место примерно на два собранных файла (`--workdir`).
- Сериал ложится в `/mnt/media/rudb/media/serials/<имя папки>`, фильм — в
  `/home/res/rudb/media/films`. Постер найдётся сам при первом показе.
- **Папка с набором фильмов** («Гарри Поттер Коллекция») — это `--films`:
  каждый файл уедет отдельной плиткой в библиотеку фильмов, имя соберётся из
  имени файла («1 Гарри Поттер и филосовский камень 2001г.mkv» → «Гарри Поттер
  и филосовский камень (2001)»): номер коллекции отбрасывается, год переезжает
  в скобки, хвост раздачи (`BDRip`, `1080p`, `x264`) срезается. Без ключа любая
  папка считается сериалом — восемь фильмов стали бы восемью «сериями».
- Имя папки сериала становится названием и запросом для постера: лучше
  «Legion (2017)», чем «Legion.S01-03.1080p.LostFilm».

## Положил и забыл: папка `convert_and_del`

Сторож `convert-watch.py` раз в десять минут смотрит
`…/rudb/temp/convert_and_del` и отправляет оттуда всё, что положили, —
руками ничего запускать не надо.

```
convert_and_del/
  films/Фильм.avi            → фильм отдельной плиткой («District.9.(dvdrip.rus).avi» → «District 9»)
  films/Коллекция/           → набор фильмов, плитка на файл (--films)
  films/Фильм (2020)/        → ровно одно видео внутри: одна плитка по имени папки
  serials/Сериал (2019)/     → сериал, структура сезонов сохраняется
```

Что он делает за прогон:

1. **Берёт только устоявшееся.** Элемент уезжает, лишь когда его размер, число
   файлов и время правки не менялись с прошлого прогона (`--settle`, по
   умолчанию 600 с). Иначе сторож подхватил бы наполовину скачанный торрент.
   На практике это 10–20 минут тишины после последней записи.
2. **Проверяет место на приставке** — `df` по той библиотеке, куда поедет
   (фильмы и сериалы лежат на разных дисках), и не берётся, если свободного
   меньше, чем весит исходник плюс запас (`--reserve`, 5 ГБ). Исходник —
   верхняя оценка: перекодирование ужимает, копия весит столько же.
   Заодно смотрит место под временный MP4 на этой машине.
3. **Зовёт `send-series.py`** — тот сам решает, что копировать, а что
   перекодировать, и отдаёт файлы по сети (`--audio 0` по умолчанию:
   приставка всё равно играет первую дорожку).
4. **Убирает исходник** — папка не зря называется `convert_and_del`. Но
   только после того, как убедится, что КАЖДЫЙ файл лёг на приставку с
   ненулевым размером; не доехало — исходник остаётся, и следующий прогон
   попробует снова (трижды, потом бросит). `--keep` отключает уборку совсем.

**Двух прогонов разом не бывает**: lock-файл в `~/.local/state/habits-convert`.
Прошлый ещё конвертирует — новый пишет строчку в журнал и выходит: файлы уже
забраны им. systemd и сам не запускает второй экземпляр oneshot-юнита, но
сторожа зовут и руками.

**Журнал** — по файлу на прогон в `~/.local/state/habits-convert/log`
(последние 200) и те же строки в `journalctl --user -u habits-convert-watch`.
Память между прогонами (отпечатки и счётчик неудач) — `state.json` там же.

```bash
./convert-watch.py --dry-run          # что взял бы и что сделал бы
./convert-watch.py --settle 0         # прогон руками, не ожидая устаканивания
./convert-watch.py --keep             # не удалять исходники
journalctl --user -u habits-convert-watch -n 50
```

`~/.config/systemd/user/habits-convert-watch.service`:

```ini
[Unit]
Description=Habits: convert_and_del -> приставка (конвертирование и отдача)
After=network-online.target

[Service]
Type=oneshot
ExecStart=/usr/bin/python3 %h/rudb/dev/go/tg/streaks/habits/media-agent/convert-watch.py
# большой сериал идёт часами — таймаут снимаем, иначе systemd убьёт на середине
TimeoutStartSec=0
# ffmpeg не должен мешать работе за машиной
Nice=10
IOSchedulingClass=idle
```

`~/.config/systemd/user/habits-convert-watch.timer`:

```ini
[Unit]
Description=Habits: проверять convert_and_del каждые 10 минут

[Timer]
OnBootSec=3min
# отсчёт от прошлого запуска: пока идёт конвертирование, новый не стартует
OnUnitActiveSec=10min
AccuracySec=1min
Unit=habits-convert-watch.service

[Install]
WantedBy=timers.target
```

```bash
systemctl --user daemon-reload
systemctl --user enable --now habits-convert-watch.timer
loginctl enable-linger $USER    # чтобы таймер шёл без входа в сессию
```

## Как добавить фотографии

`send-photos.py` отдаёт ZIP-архив на мини-сервер одним файлом и распаковывает
его там в `/home/res/rudb/media/foto`:

```bash
P=habits/media-agent/send-photos.py
python3 $P "/путь/Свадьба.zip" --dry-run               # план: альбом, число снимков, место
python3 $P "/путь/Свадьба.zip"                         # поехали
python3 $P "/путь/снимки.zip" --name "Отпуск 2026"     # своё имя альбома
python3 $P "/путь/Свадьба-ещё.zip" --merge             # дописать в существующий альбом
```

- Папка внутри архива становится альбомом; снимки прямо в корне архива —
  альбом по имени архива (или `--name`). Вложенные папки сохраняются.
- Распаковка идёт в скрытую папку и переезжает на место одним `mv`: медиатека
  не увидит полупустой альбом. `__MACOSX`, `.DS_Store`, `Thumbs.db` не
  распаковываются. Альбом с таким именем уже есть — без `--merge` скрипт
  остановится.
- В конце скрипт открывает альбом у агента, и тот в фоне собирает превью и
  копии под экран (~1 с на снимок 24 Мп на i3): к просмотру всё готово.

Видеоролики кладутся в `/home/res/rudb/media/video` как есть (MP4) — вручную
или тем же `send-series.py` с `--dest-root /home/res/rudb/media/video`.

`recode-remote.py` — другое: перекодирует то, что **уже лежит** в библиотеке
мини-сервера (забрать → собрать здесь → вернуть), удаляя исходники; ночью
пережидает пропажу сети. `send-film.py` — старый вариант для одного фильма.

### Звуковые дорожки на приставке

Приставка играет **только первую** дорожку MP4: `<video>` в Chrome и WebView не
умеет переключать встроенные дорожки (API `audioTracks` выключен в Chromium, проверено
на Chrome 136). Поэтому по умолчанию берём одну нужную. Как получить выбор
перевода — см. BACKLOG («несколько звуковых дорожек»).

## Подготовка библиотеки

Приставка играет только MP4: MKV и AVI она не открывает, хотя кодеки внутри
чаще всего подходящие. `tvconvert.py` готовит библиотеку заранее — и заодно
раскладывает её под Plex. Ничего не делает без `--apply`.

```bash
python3 tvconvert.py plan    /путь/к/сериалу              # что нашлось
python3 tvconvert.py convert /путь/к/сериалу --apply      # в MP4
python3 tvconvert.py rename  /путь/к/сериалу --apply      # имена под Plex
```

MKV с годными кодеками только **перепаковывается** (`-c copy`) — это идёт со
скоростью диска и не трогает качество. Настоящее перекодирование нужно лишь
там, где не годится сам кодек: звук AC3/DTS или видео MPEG-4 из AVI.

## Два режима плеера

После «Начать» в шапке переключатель: **🎬 Визуальный** (по умолчанию) и
**📁 Файлы** (дерево папок, как раньше). Выбор запоминается на приставке.

Визуальный режим объединяет все библиотеки и раскладывает их **по структуре
папок**, а не по названиям:

- **сериал** — папка, внутри которой папки с видео (сезоны);
- **фильм** — видеофайл или папка ровно с одним видеофайлом;
- папка с несколькими видео без сезонов — сериал из одного сезона;
- **музыка** — каждая папка, где прямо лежат треки (пустые не показываются);
  подпапки альбома (CD1, CD2, «Бонусы») — не отдельные плитки, а части одной:
  их можно включить отдельно и в каталоге, и в выборе музыки под фильм
  («Играть всё» собирает всё по порядку, `/api/tracks`); треки прямо в корне
  библиотеки — своя плитка с её названием;
- **видеоролики** (библиотека вида `clips`) — ролик прямо в корне своей
  плиткой, папка с роликами — плиткой на папку; ролики папки идут подряд;
- **фото и видео** (вид `photo`) — папки первого уровня, где есть снимки или
  ролики (хоть во вложенных папках); файлы прямо в корне — одной плиткой.

Разделы «Видеоролики» и «Фото и видео» пустыми не показываются.

**Под карточками в списке ничего нет** — только постер и название: кнопки под
каждой плиткой растягивали сетку вдвое и оттесняли сами постеры.

- **«ℹ Инфо»** — на экране сериала и на экране папки. У фильма своего экрана
  нет (карточка сразу его включает), поэтому его «Инфо» открывается кнопкой
  **в панели плеера, следом за «🌙 Сон»**: видео встаёт на паузу, место
  запоминается, «Назад» возвращает к карточке.
- **«＋ В очередь»** появляется под карточками, только когда очередь собирают:
  в шапке, рядом с «🎬 Визуальный» и «📁 Файлы», есть **«＋ Создать очередь»**.
  Нажали — под плитками (и в общем списке, и внутри папки) появились кнопки,
  набрали что нужно, нажали «✔ Готово» — кнопки убрались. Сам раздел
  «Очередь» с «▶ Смотреть очередь» показывается всегда, пока очередь не пуста.

## Папки: «Гарри Поттер», «Фантастические твари»

Фильмы одной вселенной собираются **в одну карточку** — чтобы смотреть подряд
и в правильном порядке. Сериалы собираются так же.

- В общем списке папка выглядит обычной карточкой фильма, только с числом
  внутри («3 фильма») — как у сериала видно число сезонов. Картинка берётся у
  первого фильма; в админке можно поставить свою.
- Внутри — шапка как у сериала: «▶ Смотреть сначала» играет всё подряд в
  заданном порядке, «＋ В очередь» ставит в очередь папку целиком (она
  развернётся в свои фильмы при просмотре), «ℹ Инфо» — описание папки. Ниже
  содержимое **карточками**, как в общем списке, а не строчками: это фильмы, у
  каждого свой постер.
- Описание папки заполняется только **вручную** (админка → «Папки» → «ℹ»): в
  интернете «коллекции» нет, а поиск по такому названию нашёл бы первый фильм
  серии.

**Папка виртуальная: файлы на диске не двигаются.** Иначе пришлось бы
перекладывать десятки гигабайт на внешнем диске и ломать «Продолжить
просмотр», отметки заставки и кадры — они привязаны к пути. Запись (список
путей и порядок) лежит в `collections.json` в кэше агента; пропавший файл при
показе молча пропускается, а переименование в админке папка переживает.

**Админка → «Папки»**: «＋ Новая папка», у каждой — «📂 Состав» (порядок
стрелками ↑↓, «☑ Только в папке», «✕» убрать, список «Добавить» ниже),
«✏ Имя», «🎨 Обложка», «ℹ» описание и «🗑». Галочка **«только в папке»**
убирает фильм из общего списка «Фильмы» — он останется виден лишь внутри
папки; без галочки он есть и там, и там. Убрать папку — не то же, что удалить
фильмы: они остаются на диске и возвращаются в общий список.

**Фото и видео.** В папке сверху снимок на большую часть экрана, снизу полоса: снимки,
за ними вложенные папки. Стрелки ходят по полосе, снимок сверху меняется вслед
за фокусом; OK — во весь экран, там стрелки листают по кругу, «Назад»
возвращает к полосе на том же снимке. Приставке уходят не оригиналы (6–8 МБ),
а копии: превью до 480 px и экранная до 1920×1080, с поворотом по EXIF. Копии
собираются по требованию стандартной библиотекой Go (без внешних программ) и
лежат в `MEDIA_CACHE/photos` с ключом «путь + размер + время правки»; открыли
папку — агент в фоне готовит копии всех её снимков, по одному. WebP и GIF
отдаются как есть.

**Постеры** агент ищет сам при первом показе плитки — IMDb для латинских
названий (с разбором «фильм или сериал» и года), Википедия для кириллических —
и кладёт **рядом** с фильмом или папкой сериала под тем же именем
(`Fauda/` → `Fauda.jpg`, `Фильм.mp4` → `Фильм.jpg`). Неудачный поиск
запоминается на сутки.

Искать пробуем тремя названиями подряд, пока не найдётся (то же и для «Инфо»):

1. **имя файла или папки**, очищенное от тегов раздачи;
2. **его начало** до двоеточия или тире — статья бывает короче названия
   раздачи: «Элизиум» вместо «Элизиум - Рай не на Земле»;
3. **название из метаданных самого файла** (тег `title`). У русских раздач имя
   файла бывает транслитом — `PoCHti.17.2016.D.BDRip` — а внутри лежит
   `The Edge of Seventeen 2016 1080p BluRay…`, по которому IMDb находит фильм
   сразу. Строка вида `Мама / Mama (2013)` разбирается на оба названия. В теге
   попадается и подпись рипера (`-=LEONARDO=-`), поэтому найденному по нему
   верим только при совпадении года, а кракозябры из CP1251 отбрасываются.

Названия сравниваются **без знаков препинания и регистра** (`ё` = `е`): у нас
в имени файла тире, а в Википедии двоеточие или длинное тире — «Фантастические
твари: Преступления Грин-де-Вальда» и «Элизиум — рай не на Земле» иначе не
совпадали бы с нашими именами. Свой постер можно подложить руками тем же именем — он
главнее найденного. Нет прав писать в папку — картинка ляжет в кэш агента.
Для видеороликов и фото постеры **не ищутся**: по имени домашнего файла нашлась
бы чужая картинка. Положенная рядом руками (`Ролик.mp4` → `Ролик.jpg`, папка →
`Папка.jpg` или `poster.jpg` внутри) показывается.

Сериал играет **сезон за сезоном**: после последней серии сезона плеер сам
берёт первую серию следующего (и в визуальном режиме, и в «Файлах»). На
главной есть **очередь** — фильмы и сериалы по порядку.

**Продолжить просмотр** — первый раздел главной: по записи на сериал или фильм,
свежие первыми (до 20, старше полугода забываются). Хранится на агенте в
`progress.json` кэша, а не в браузере приставки. Плеер шлёт id файла и секунду
раз в 15 с, на паузе, при выходе из плеера и в конце серии; к какому сериалу
относится серия, агент выясняет по папкам сам. Правила:

- первая минута чужой серии место не затирает (случайное включение);
- осталось меньше 2 минут или 3% — серия досмотрена, запись переходит на
  следующую серию с нуля, в том числе через сезон; досмотрен сериал или фильм —
  запись удаляется;
- возобновление ставит на 5 секунд раньше места остановки;
- после перекодирования (`S01E05.avi` → `S01E05.mp4` меняет id) запись находит
  серию по пути без расширения.

## Приложение для Android TV

Браузер приставки работает курсором; приложение `habits/tv-app` открывает эту же
страницу и передаёт ей настоящие стрелки пульта. Страница узнаёт его по
`HabitsTV/` в User-Agent: сама нажимает «Начать», показывает «⚙ Адрес», а кнопку
«Назад» пульта обрабатывает `window.habitsBack()`. Во весь экран OK пульта
(Enter) и Play/Pause ставят видео на паузу и запускают снова, стрелки влево и
вправо мотают на 30 с (поверх видео на секунду видно позицию).

## Музыка

- **«Музыка на паузе»** — галочка на панели плеера. Видео на паузу — играет
  музыка (очередь пуста — первая музыкальная папка), видео пошло — музыка на
  паузу и в следующий раз продолжит с того же места. Паузы, которые ставит сама
  страница (выход в каталог, «⏹», конец серии), не в счёт. Помнится на сессию
  страницы (`sessionStorage`).
- **Как играть** — «➡ Один раз» (очередь до конца и стоп), «🔁 Весь плейлист»
  (по кругу), «🔂 Один трек» (текущий по кругу); **порядок** — 🔢 прямой или
  🔀 случайный: текущий трек остаётся на месте, остальные звучат по разу,
  «Играть всё» начинает со случайного. Оба выбора — в `localStorage` приставки. В обычном браузере в шапке
справа значок Android — ссылка на APK, если он выложен (`tv-app/build.sh
--deploy` кладёт его в `MEDIA_CACHE/app/habits-tv.apk`).

## Несколько плееров одной медиатеки

Показ с телефона («Отправить на ТВ») ставит просмотр на паузу и возвращает
его при закрытии показа; «Музыка на паузе» в это время молчит. Пока показ
открыт, OK, стрелки и кнопки пульта управляют им, а не сериалом.

Страницу можно открыть и на телевизоре, и на компьютере — это два «экрана»
одной комнаты (комната = агент). Прод выдаёт каждому номер, страница
подписывает им свои ответы и называет себя («Приложение на ТВ», «Браузер
приставки», «Браузер компьютера»), а рядом с кодом показывает, какой это
экран. В пульте появляется выбор экрана: команды и картинка с телефона идут
только выбранному.

## Оформление, заставки, сон, слайд-шоу

- **Фон страницы** — админка, «Оформление»: снимок из «Фото» (стрелками) или
  файл с компьютера; размытие и затемнение — стилями страницы, на ходу. Лежит
  в `MEDIA_CACHE/app/background.jpg`, настройки — `looks.json`. На экране
  сериала и папки роликов вместо общего фона — их постер, сильно размытый. В
  плеере и «Файлах» фона нет.
- **Обложки** — «🎨» у строки админки: папке — скрытый `.cover.jpg` внутрь
  (главнее всего, переезжает и удаляется вместе с папкой), файлу — `Имя.jpg`
  рядом. Музыка и альбомы фото показывают только свои обложки (альбом без неё
  — первый снимок).
- **Заставка и титры** — отметки трёх уровней: на весь сериал, на сезон и на
  отдельную серию (`marks.json`; ключ — хеш пути, рядом лежит и сам путь, чтобы
  запись переехала за переименованием). Играет самая точная: у серии — её
  собственная, иначе сезонная, иначе общая; заставка и титры наследуются
  порознь. Начало и конец заставки считаются от начала серии, титры — от конца
  (серии разной длины, титры одинаковые); «титры кончаются» — тоже от конца:
  0 — идут до самого конца, иначе после них сцена и пропуск ведёт к ней.
  Во время заставки — «⏭ Пропустить заставку», на титрах — «Следующая серия
  через 10 с» (а если после титров есть сцена — «⏭ Пропустить титры»); во весь
  экран OK жмёт кнопку, «Назад» отказывается.
- **Где отмечать.** В админке «✂» у сериала или фильма: выбираете сезон, потом
  серию — она играет прямо в админке. Доводите до места (⏯ и шаги ±1/10/60 с),
  жмёте «Заставка начинается» / «Заставка кончается», «Титры начинаются» и либо
  «Титры до конца серии», либо «Титры кончаются» (после них сцена). Уровень
  записи выбирается кнопками «Весь сериал / Сезон / Только эта серия», там же
  «Пропускать заставку сам» и сброс своего уровня; ниже видно, что записано на
  каждом уровне. Та же панель есть и в плеере — «✂» под видео, с выбором
  уровня.
- **«🔎 Взять из глав файла»** — в mkv часто есть главы «Opening», «Ending
  Credits»: агент читает их через `ffprobe` (`GET /api/marks/chapters?file=`) и
  ставит отметки сам. Заставкой считается только глава из первой четверти
  серии, титрами — из последней трети; если после титров есть ещё глава,
  записывается и конец титров.
- **«🎧 Найти заставку и титры по звуку»** — кнопка на экране выбора сезона в
  «✂»: агент сам размечает весь сезон или сериал (`POST /api/admin/marks/scan`,
  ход работы — `GET`, остановка — `POST …/stop`). Заставка у серий одного сезона
  звучит одинаково, её и ищем: с каждой серии снимаются «отпечатки» звука
  (моно 8 кГц, окно 256 мс с шагом 64 мс, по биту на пару из 21 полосы спектра
  — `fingerprint.go`), первые 20 минут и последние 15; серия сравнивается с
  четырьмя другими перебором сдвигов, и самый длинный общий кусок становится
  отметкой. Записывается на уровне серии: пролог у каждой свой длины.
  Галочка «Пропускать с самого начала» ставит начало заставки в 0 — вместе с
  повтором прошлых серий, который по звуку не найти. Конец заставки дотягивается
  до ближайшей паузы: в последние секунды поверх той же музыки называют эпизод,
  и совпадение там обрывается. Титры, которые «нашлись» не там, где у всего
  сезона, подтягиваются к сезонной медиане. Считает одну задачу за раз, на i3
  сезон — минут двадцать (в основном чтение и раскодирование звука).
- **«⏭ Пропуск: вкл/выкл»** — кнопка рядом с «⛶ Во весь экран»: выключает
  подсказки пропуска у этого сериала, не стирая отметки (`skip_off`, пишется на
  сериал; включённый где угодно уровень действует на все).
- **🌙 Сон** — через 15/30/60/90 минут или после этой серии: звук за 15 с
  уходит, видео и музыка встают на паузу.
- **Во весь экран** стрелки ↑↓ — ±5 минут или громкость (выбор в «Оформлении»).
- **Ролики в альбомах фото** — видео рядом со снимками: в полосе со значком
  ▶ (кадр вынимает ffmpeg), смотрятся в просмотрщике во весь экран.
- **▶ Слайд-шоу** — первая кнопка полосы альбома: каждые 3–12 с, по порядку или
  вперемешку, с плавной сменой, под музыку из библиотеки — папкой по кругу или
  одной песней по кругу. OK — пауза, «Назад» — выход (музыка встаёт, прежний
  режим повтора возвращается). Настройки запоминаются на приставке.

## Кадры для «Инфо» и фоновые задачи

- **Кадры** — десяток картинок из фильма под описанием в «Инфо»: постер
  показывает, как фильм продавали, а кадры — как он выглядит. Берутся из
  середины (первые 8 % и последние 8 % не трогаем — там заставка и титры),
  слишком тёмные пропускаются: в случайном месте легко попасть в затемнение
  между сценами. У **сериала** кадры общие на весь сериал — по одному из
  десятка случайных серий, а не пачка с каждой: сто картинок никому не нужны,
  да и разбирать их полчаса.
- **Где запускать** — админка, «Задачи»: «📚 Вся медиатека» (только там, где
  кадров ещё нет) или «🎬 Только фильмы». Отдельный фильм или сериал — кнопка
  «🎞» у строки медиатеки: там же список кадров, «🎬 Собрать заново»,
  «📸 Кадр из серии» (видео с шагами ±1/10/60 с — снимок с текущего места),
  «⬆ Свой файл» и у каждого кадра «🎨» (сделать обложкой плитки) и «🗑».
  Свои кадры идут первыми и при пересборке не трогаются.
- **Хранятся** в кэше агента (`frames/<id>/`), а не рядом с фильмом: библиотека
  остаётся чистой. За переименованием едут следом; пропадут — соберутся заново.
- **Фоновые задачи** — «Задачи» в админке: что идёт сейчас, сколько сделано,
  отчёт по каждому элементу и «✖ Остановить». Сюда же попал поиск заставки по
  звуку. Задачи идут **по одной**: и ffmpeg, и чтение с внешнего диска отбирают
  силы у самого просмотра. Список живёт до перезапуска агента.

## «Инфо», плейлисты, загрузка музыки, статистика

- **Что внутри файла** — строка под описанием в «Инфо»: разрешение, кодек,
  битрейт видео и всего потока, длительность, размер, а ниже все звуковые
  дорожки с языком, подписью раздачи и битрейтом и число дорожек субтитров. У
  сериала берётся первая серия (`media` в ответе `/api/info`). То же короткой
  строкой — в админке под каждым файлом и под плиткой фильма: видно, что за
  раздача и сколько в ней лишнего, ещё до отправки.
- **＋ В очередь** у плитки: раздел «Очередь» с кнопкой «▶ Смотреть очередь»
  появляется сразу, на том же месте списка и с тем же фокусом (перерисовка
  главного экрана помнит, на какой кнопке стоял пульт), а сама плитка
  переключается на «✓ В очереди» — и остаётся такой после перерисовок.
- **ℹ Инфо** у фильмов и сериалов на главной: описание, год, жанры, оценки,
  актёры. Агент ищет при первом открытии (`GET /api/info`): подсказки IMDb →
  Wikidata по id IMDb (жанры, актёры, дата, оценки критиков) → Википедия
  (описание, ru или en) → TVmaze для сериалов (рейтинг зрителей). Кириллическое
  название — через поиск Википедии. Хранится рядом с постером: `Имя.info.json`
  (едет при переименовании и в корзину). В админке «ℹ» у строки: найти заново,
  «искать как…», поправить поля руками, очистить. В User-Agent — ссылка на
  репозиторий и не чаще запроса в 300 мс: иначе Wikimedia отвечает «too many requests».
- **Плейлисты** — `playlists.json` в кэше: «＋» у трека, «＋ Всю папку в
  плейлист»; плейлисты первыми в «Музыке», доступны в выборе музыки под фильм,
  в слайд-шоу и «Музыке на паузе».
- **〰 Плавно** — переход между треками за 4 с (второй `<audio>`). Элементы
  меняются местами по времени (за 0,25 с до конца), а не по событию: Chrome в
  конце трека присылает ещё и «паузу», и она отменяла переход — следующий трек
  начинался заново.
- **☰ Плейлист** на панели музыки — окно очереди поверх экрана: что играет и
  что дальше, текущий трек выделен, внизу полоска и проценты трека; строку
  можно нажать и включить её сразу. «Назад» закрывает. Сам прогресс трека виден
  всегда — тонкой полоской по верхнему краю панели музыки.
- **Список папки** — подпапки строками (в них заходят, как в папку), ниже свои
  треки; играющий трек выделен и помечен «♪» или «⏸». «▶ Играть всё» по-прежнему
  берёт альбом целиком, со всеми дисками.
- **Дозагрузить в готовый альбом** — «📥» у папки в админке: несколько файлов
  сразу или ZIP-архив. Файл не той библиотеки не берётся, занятое имя получает
  «(2)», папка-обёртка из архива снимается (подпапки внутри сохраняются).
- **Собрать альбом** — вкладка «Собрать» в админке: создать альбом или папку
  внутри него, открыть любую другую папку, послушать трек («▶») и добавить
  копией («＋») или перенести («→»); «＋ Все» и «→ Все» — всю папку. Источник
  можно менять сколько угодно, цель остаётся. Перенос в пределах диска — это
  rename (мгновенно, без второй копии), между дисками — копия и удаление
  исходника только после успешной копии.
- **Альбом ZIP** — админка, «Медиатека»: «🎵 альбом музыки» и «🖼 альбом фото
  и видео» (браузер на компьютере). Загрузка частями по 768 КБ
  (`/api/admin/upload`, `target=music-zip|photo-zip`). Папка внутри архива —
  альбом, подпапки сохраняются (у музыки это диски, см. «части»); берутся только нужные
  файлы (треки либо снимки и ролики) плюс обложки и тексты песен; имена CP866
  из Windows-архиваторов декодируются.
- **Статистика** — админка, «Статистика»: часы по дням за 7 или 30 дней и
  самое смотримое (`stats.json`; в зачёт только воспроизведение).
- **Отправить на ТВ** — «Пульт ТВ» в Telegram → «🖼 Фото или видео»: файл через
  прод (`/api/v1/tv/cast`), на приставке слой поверх всего, «Назад» — закрыть.

## Админка

Значок ⚙ в шапке страницы (рядом с 🔄 «обновить» и значком приложения).
Закрыта PIN-кодом `admin_pin`: в домашнем вайфае живёт не только приставка, а
здесь удаляют сериалы. PIN спрашивается один раз на устройстве и хранится в его
браузере; пять неверных подряд — пауза 5 минут. Без `admin_pin` админка выключена.

- **Медиатека** — все разделы с настоящими путями и размерами. «✏ Имя»
  переименовывает на диске: у файла расширение сохраняется само, постер-сосед
  (`Имя.jpg`) и записи «Продолжить просмотр» переезжают следом. «📂 Файлы» —
  внутрь: сезоны, серии, посторонние файлы. «🖼 Постер» — найти заново.
- **Удаление** — в корзину `<корень библиотеки>/.habits-trash/<id>/` (тот же
  диск, переезд мгновенный) вместе с постером-соседом. Через `trash_days` дней
  стирается само (проверка раз в 30 минут), до этого — «↩ Вернуть» (не
  затирает то, что появилось на старом месте) или «✖ Стереть» сразу. Список —
  `MEDIA_CACHE/trash.json`. Корень библиотеки не удаляется и не переименовывается.
- **Уведомления** — о переносе в корзину, возврате и стирании агент пишет
  владельцу приставки в Telegram через прод: `POST /api/v1/tv/notify`
  (адрес — из `hub`, `wss://…/socket` → `https://…/notify`), пропуск — ключ
  комнаты. Пока к приставке не подключали пульт, писать некому.
- **Обслуживание** — место на дисках библиотек, копии фото (очистить), ненайденные
  постеры (искать сейчас), «Продолжить просмотр» (очистить), проверочное
  уведомление, «забыть PIN» на этом устройстве.

## API (локальный)

| Запрос | Ответ |
|---|---|
| `GET /api/libraries` | список библиотек |
| `GET /api/browse?id=` | содержимое библиотеки или папки |
| `GET /api/catalog` | фильмы, сериалы с сезонами, папки-подборки, видеоролики, фото и музыка для визуального режима |
| `GET /api/photos?id=` | снимки папки (ссылки на превью и экранную копию) и вложенные папки со снимками |
| `GET /photo/{id}?k=&s=thumb\|view` | копия снимка: превью или под экран (соберёт, если нет) |
| `GET /api/item?id=` | один файл с разбором и ссылкой |
| `GET /api/next-season?id=<файл>` | серии следующего сезона того же сериала |
| `GET /poster/{id}?k=&kind=` | постер плитки (для фильмов и сериалов найдёт и сохранит рядом, если нет) |
| `GET /api/progress` | «Продолжить просмотр», свежие сверху |
| `PUT` или `POST /api/progress` `{file, position, duration}` | запомнить место; POST — для `sendBeacon` при закрытии страницы |
| `DELETE /api/progress/{key}` | убрать запись |
| `GET /app/habits-tv.apk` | приложение для Android TV (404, пока не выложено) |
| `GET /api/info?id=` · `POST /api/admin/info` | «Инфо» о фильме или сериале; найти заново, поправить, очистить |
| `GET /api/tracks?id=` | треки папки со всеми вложенными (альбом с дисками) |
| `POST /api/admin/mkdir {name, id?, kind?}` | новая папка: внутри папки или в корне библиотеки |
| `POST /api/admin/transfer {ids, to, move}` | скопировать или перенести файлы в папку |
| `GET`/`POST /api/playlists` · `GET /api/playlists/{id}` · `POST …/add` · `…/remove` · `…/rename` · `DELETE …/{id}` | свои плейлисты |
| `POST /api/admin/upload` · `PUT …/{id}?offset=` · `POST …/{id}/finish?target=music-zip\|background\|cover` | загрузка частями |
| `GET /api/stats?days=` | статистика просмотра |
| `GET /api/settings` · `GET /background` | оформление для страницы и картинка фона |
| `GET` / `PUT /api/marks?file=` `{file, scope: series\|season\|episode, intro_start, intro_end, credits_from_end, credits_end_from_end, auto_skip, reset}` | заставка и титры: общая, сезонная или серии |
| `GET /api/marks/chapters?file=` | главы файла и отметки, которые из них вышли |
| `POST /api/admin/marks/scan {id, from_start}` | поиск заставки и титров по звуку |
| `GET /api/frames?id=` · `GET /frame/{id}/{name}?k=` | кадры элемента и сама картинка |
| `POST /api/admin/frames/scan {scope: all\|films\|item, id?, redo?}` | собрать кадры |
| `POST /api/admin/frames/add {file, at}` · `…/delete {id, name?}` · `…/cover {id, name}` | свой кадр, удаление, обложка из кадра |
| `GET /api/admin/tasks` · `POST /api/admin/tasks/{id}/stop` | фоновые задачи: что идёт и остановка |
| `GET /api/admin/collections` | папки и полный список фильмов и сериалов, из которых их собирают |
| `POST /api/admin/collections {name}` · `POST …/{id} {name?, set_members, members:[{id,only}]}` · `DELETE …/{id}` | создать папку, задать имя и состав (порядок = порядок просмотра), убрать |
| `POST /api/admin/settings` · `POST`/`DELETE /api/admin/image?target=background\|cover&id=` | оформление, фон и обложки (тело — картинка или `{photo_id}`) |
| `GET /api/admin/check` · `overview` · `children?id=` · `trash` · `service` | админка (заголовок `X-Admin-Pin`) |
| `POST /api/admin/rename {id,name}` · `delete {id}` · `poster/reset {id}` | переименовать, в корзину, постер заново |
| `POST /api/admin/trash/{id}/restore` · `…/purge` · `service/{action}` | вернуть, стереть, обслуживание |
| `GET /api/jobs` | очередь перекодирования |
| `POST /api/jobs` `{"id","profile"}` | поставить задачу (профиль по умолчанию — из вердикта разбора) |
| `POST /api/jobs/{id}/stop` | снять задачу |
| `GET /media/{id}?k=` | файл, с поддержкой Range |

Профили: `remux` (только контейнер), `audio` (видео копируется, звук в AAC),
`video` (всё заново). Результат ложится в кэш, и по той же ссылке начинает
отдаваться он вместо оригинала.
