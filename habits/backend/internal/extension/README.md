# Habits — расширение браузера

Тонкая оболочка: попап 400×600 с приложением, которое грузится **с сервера**.
Поэтому расширение не нужно перевыпускать при каждом релизе Habits — обновления
приезжают сами.

## Откуда брать

| Адрес | Что это |
|---|---|
| `GET /ext/habits-chrome.zip` | архив для Chrome, собирается в памяти и кэшируется |
| `GET /ext/habits-firefox.xpi` | **подписанный Mozilla** файл для Firefox |
| `GET /ext/updates.json` | манифест обновлений, на него ссылается сам `.xpi` |
| `GET /ext/habits-firefox.zip` | неподписанный, для разработки (временная установка) |

Ссылки на скачивание есть в приложении: **Settings → Токены доступа → Где
использовать токен**. В `popup.html` и манифесте при сборке подставляется адрес
приложения (`{{APP_URL}}` ← `PUBLIC_URL`), поэтому скачанное расширение
указывает на тот сервер, откуда его взяли.

## Установка

**Chrome:** распаковать архив → `chrome://extensions` → «Режим разработчика» →
«Загрузить распакованное расширение» → выбрать папку.

**Firefox:** открыть `.xpi` в браузере и подтвердить установку (или
`about:addons` → шестерёнка → «Установить дополнение из файла»). Ставится
постоянно и обновляется само.

## Подпись для Firefox

Firefox ставит неподписанное дополнение только временно — до перезапуска.
Подпись снимает это ограничение. Канал — **unlisted**: Mozilla подписывает
файл, но не публикует его в каталоге, проверка автоматическая (секунды),
раздаём мы его сами.

```bash
./sign-firefox.sh                      # прод-адрес по умолчанию
./sign-firefox.sh https://dev.host/    # другой сервер
```

Ключи API берутся из `~/.config/habits-amo.env`
(`AMO_JWT_ISSUER` / `AMO_JWT_SECRET`, `chmod 600`, **вне репозитория**);
получить их: addons.mozilla.org → Developer Hub → Manage API Keys.

Результат — `files/signed/habits-firefox.xpi`, он вшивается в бинарник. Это
**единственный бинарник в репозитории**, и по-другому нельзя: подпись покрывает
байты архива, пересобрать его на лету, как zip, невозможно. По той же причине
адрес приложения зашит внутрь в момент подписи.

⚠️ При каждой новой подписи нужно **поднимать `version`** в
`files/manifest.firefox.json` — AMO не примет повторно уже загруженную версию.
Версия и id для `updates.json` читаются из самого `.xpi`, чтобы не разъехались.

Подписывать заново нужно только при изменении самого расширения (манифест,
попап, иконки, адрес сервера). Релизы Habits расширения не касаются.

## Исходники

| Файл | Назначение |
|---|---|
| `files/manifest.chrome.json` | манифест MV3 для Chrome |
| `files/manifest.firefox.json` | манифест MV3 + `browser_specific_settings` (id, `update_url`) |
| `files/popup.html` | попап; `{{APP_URL}}` заменяется при сборке |
| `files/icons/` | иконки 16/48/128 |
| `files/signed/habits-firefox.xpi` | подписанный артефакт (не редактировать руками) |
| `extension.go` | embed + сборка zip + кэш |
| `signed.go` | раздача `.xpi` и манифест обновлений |
| `sign-firefox.sh` | подпись на AMO |

Вход — по персональному токену (Settings → «Токены доступа»); токен лежит в
localStorage окна расширения и никуда не уходит.
