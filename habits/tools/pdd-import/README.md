# Импорт колоды «ПДД Армении» для страницы «Тесты»

Вопросы **не хранятся в репозитории и не заливаются миграцией**: 1032 вопроса
и 669 картинок внутри `.sql` невозможно ни прочитать, ни исправить. Вместо
этого — воспроизводимая сборка из открытых источников и идемпотентный импорт
через админский эндпоинт.

## Источники

| Что | Откуда | Роль |
|---|---|---|
| Вопросы (1032, ru) | [alexmasyukov/pdd-armenia](https://github.com/alexmasyukov/pdd-armenia) — `ru_2026.json` | рабочий набор |
| Картинки (669, webp) | тот же репозиторий, `public/images/questions/` | схемы и знаки |
| Официальные PDF | `https://roadpolice.am/exam/ru_group_{1..10}.pdf` | **эталон для сверки** |

Набор извлечён из тех же официальных PDF полуавтоматически (ИИ по
скриншотам), поэтому перед импортом он сверяется с первоисточником. PDF в
репозитории-источнике побайтово совпадают с теми, что отдаёт roadpolice.am.

## Сборка пакета

```bash
python3 build_bundle.py --work ./_pdd --out ./_pdd/bundle
```

Скачает источники, прогонит сверку (`verify.py`) и положит `deck.json`
(~445 КБ) и `images.zip` (~11 МБ). Нужен `poppler-utils` (`pdftotext`,
`pdfinfo`).

## Сверка (`verify.py`)

Официальный PDF свёрстан в две колонки: в каждой — вопрос, варианты «1.…2.…»
и маркер ответа (`отв․՝2`, в восьмой группе `Отв. 2`). Без `-layout`
pdftotext рвёт связь ответа с вопросом, поэтому страница режется по вертикали
и колонки читаются отдельно.

- **Постраничная проверка (решающая)** — мультимножество правильных ответов
  страницы против ответов тех же шести вопросов набора. Не зависит ни от
  порядка внутри страницы, ни от повторов формулировок. Расхождение → импорт
  не собирается.
- **Повопросная (информативная)** — сколько вопросов сопоставилось с PDF
  дословно по вариантам.

Результат на комплекте от 25.12.2025: **174 страницы без единого противоречия**
(158 полных совпадений, 16 частично разобранных), 783 вопроса подтверждены
дословно, 124 неоднозначны (у картиночных вопросов варианты повторяются слово
в слово — различает только схема), 119 не сопоставлены.

Шесть вопросов скрипт помечает как «требуют проверки глазами». Все шесть
проверены по отрисованным страницам:

```bash
pdftoppm -f 1 -l 1 -r 110 -png _pdd/pdf/ru_group_5.pdf стр
```

— маркер ответа на странице совпал с набором, ошибался разбор колонок.

### Дефект первоисточника

У вопроса 854 (группа 8, стр. 13) в **русском** PDF напечатаны три варианта, а
правильный ответ — «Отв. 4»: при вёрстке потеряли строку. В английской версии
(`en_group_8.pdf`, та же страница) она на месте — «4.In all the cases listed.»
с «Ans․՝4». Вариант возвращён по-русски заплаткой `PATCHES` в
`build_bundle.py`; каждая заплатка обязана ссылаться на официальный документ.

## Импорт

```bash
curl -X POST "$BASE/api/v1/admin/tests/import" \
     -H "Authorization: tma <initData>" \
     -F "deck=@_pdd/bundle/deck.json" \
     -F "images=@_pdd/bundle/images.zip"
```

Идемпотентно по `(deck.slug, question.num)`: повторный импорт обновляет тексты
и ответы, **не сбрасывая прогресс пользователей** — id вопросов сохраняются.
Картинки распаковываются в `DATA_DIR/tests` и раздаются из `/uploads/tests/`.
Ответ: `{"deck_id":1,"inserted":1032,"updated":0,"images":669}`.

## Обновление комплекта

Полиция периодически обновляет вопросы. Тогда: поменять даты в `QUESTIONS_URL`
и `DECK["revision"]`, пересобрать пакет (сверка укажет на расхождения) и
импортировать заново.

## Дымовой прогон

`smoke_test.sh` — 12 проверок против локального сервера: пулы вопросов,
скрытие правильного ответа до ответа, переход вопроса в «пройден», стабильность
порядка, экзамен с таймером и вердиктом, разбор, настройка порога, сброс,
раздача картинок, идемпотентность импорта.
