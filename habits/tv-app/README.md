# Habits TV — приложение для Android TV

Открывает медиатеку (страницу плеера медиаагента) на весь экран. Зачем, если
есть браузер: встроенный браузер приставки водит **курсором**, а приложение
передаёт странице настоящие кнопки пульта — стрелки ходят по плиткам, OK
открывает. Плюс не нужно нажимать «Начать»: автовоспроизведение в приложении
разрешено.

## Пульт

| Кнопка | Что делает |
|---|---|
| стрелки, OK | навигация по странице |
| «Назад» | шаг назад: из плеера, с экрана сериала, из папки; на главной — выход |
| **долгое «Назад»** | адрес медиатеки (работает, даже если страница не открылась) |
| «⚙ Адрес» в шапке страницы | то же самое |

Адрес по умолчанию — `http://192.168.0.79/tv/`. Роутер выдал компьютеру другой —
меняется в настройках, переустанавливать не нужно. Схему `http://` можно не
набирать. Если страница не открылась, приложение покажет адрес, ошибку и кнопки
«Повторить» / «Изменить адрес».

## Сборка

```bash
./build.sh            # dist/habits-tv.apk
./build.sh --deploy   # собрать и выложить на мини-сервер
```

Нужны JDK 17 и Android SDK (`~/Android/Sdk`). **Ключ подписи** создаётся при
первой сборке в `~/.config/habits-tv/` и в репозиторий не попадает — не теряйте
его: обновление, подписанное другим ключом, поверх старой версии не встанет.

Цель — Android 14 (targetSdk 34), а не новее: у приложений под Android 16
кнопку «Назад» забирает системный жест, и шаг назад по странице переставал
работать. Минимальная версия — Android 5.

## Установка на приставку

**Через ссылку.** Медиаагент раздаёт APK по `http://192.168.0.79/tv/app/habits-tv.apk`;
в браузере в шапке медиатеки справа значок Android. Скачать на приставке любым
браузером или файловым менеджером и открыть; при первой установке Android
попросит разрешить установку из этого источника.

**Через adb с компьютера** — на приставке: «Настройки → Об устройстве» семь раз
нажать на номер сборки, затем «Для разработчиков → Отладка по сети»:

```bash
adb connect <адрес-приставки>:5555    # на телевизоре подтвердить подключение
adb install -r dist/habits-tv.apk
```

После установки значок «Habits TV» появится среди приложений на главном экране.
